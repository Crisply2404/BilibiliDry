# 技术设计: 自动跳过注水 v2 + 开发者对比视图

## 技术方案

### 核心技术
- Chrome Extension（MV3）
- content script 注入浮层（视频页上运行）
- dashboard 页面用于开发者对比（仅开发者模式显示）

### 实现要点

#### 1) 自动跳过的“产品规则”落地
我们把自动跳过拆成两条最容易理解的规则：
1. **用户手动拖进注水段：不强制跳过**（尊重用户）
2. **正常播放即将进入注水段：自动绕开**（省时间）

落地方式：
- 用 `seeked` 事件判断“这次跳转是不是用户手动拖动造成的”。
- 如果用户拖进了注水段，就记录一个“允许观看到什么时候”的时间点（直到当前注水块结束）。
- 自动跳过的定时器检查当前播放时间：
  - 若正在注水段里且没被“允许观看”保护 → 直接跳到注水块结束
  - 若还没进入注水段，但 1 秒左右就要进入 → 提前绕开（更像“自动避水”）

#### 2) 跳转目标用“注水块”而不是“下一段干货起点”
为了避免片段边界不完美、或注水片段挨得很近导致的跳转怪异：
- 计算“与当前注水段相连的一整段注水块”（取并集/连通块）
- 跳转目标是“注水块的结束时间”

这样用户体感会更稳定：**跳过就是跳过这一整段注水**。

#### 3) 取对播放器的 video 元素（避免取错）
B 站页面可能同时存在多个 `<video>`（比如隐藏元素/预览/广告等）。
如果拿到的是“看不见的 video”，设置 currentTime 就会表现得很怪（看起来像没跳、或跳错）。

策略：
- 找到所有 video
- 过滤掉不可见/太小的
- 选面积最大的那个作为播放器

#### 4) UI 上直接显示开关状态
避免“我到底开没开”的疑惑：
- 在开关描述里直接显示 `已开启/已关闭`

#### 5) 只做“自动跳过开关”，不做手动跳过按钮
你明确要求产品形态是：
- 只有一个“自动跳过注水”的开关
- 不要“点一下跳一下”的手动按钮

所以实现上会移除浮层里的手动跳过按钮，避免用户混淆“到底是自动还是手动”。

## 注水原因中文标签（卡片/热力图）

### 目标
让用户看到的是“人话”标签，而不是英文枚举值：
- 重复 / 广告 / 无信息增量 / 寒暄 / 跑题

### 实现方式
- 建一个统一的映射函数（例如把 `REPEAT` 显示成“重复”）
- Heatmap 的 tooltip、以及任何显示注水原因的卡片，都统一走这个映射
- 优先展示：
  - `waterReasonText`（模型给的中文短语，如“重复讲概念”）
  - 同时附一个“原因标签”（例如“重复”），便于快速扫一眼

## 开发者对比视图（仅开发者模式）

### 目标
让你面试时能讲清楚两件事：
1. **我们怎么省成本/省时间**（Model Cascade 指标）
2. **我们怎么保证质量**（关键干货校验/修复次数）

### 设计方向（推荐）
- dashboard 在开发者模式下增加一个“对比区”：
  - 默认对比：最新一次 run vs 上一次 run
  - 或者提供下拉选择两个 run
- 对比维度：
  - 总耗时、请求/响应字符数（近似成本）
  - 校验结果：pass/weak/fail 数量、平均分、修复次数

普通用户模式：不展示任何开发者面板（保持干净）。

## Dashboard 可用性完善（播放/跳转/逻辑积木）

### 目标（分层交付）
1) **最低可用**：Dashboard 里的卡片/片段点击后，能打开 B 站并跳到对应时间点（绝对要做到）。
2) **进阶体验**：Dashboard 内嵌播放器能播放（如果被 B 站限制，则自动降级到“打开新标签页跳转”）。
3) **逻辑积木初版**：别再永远空白；先做一个“可用的 v0”，再逐步用 LLM 提升质量。

### 播放实现思路（推荐 + 降级）
- 推荐：使用 B 站的 embed 播放器（iframe，`player.bilibili.com`），通过更新 iframe URL 的 `t=` 参数来定位时间点。
- 降级：如果 iframe 被限制（看不到或报错），就改成点击后新标签页打开：`https://www.bilibili.com/video/BV...?...&t=秒数`

### 逻辑积木实现思路（v0 → v1）
- v0（快速可用）：先基于现有干货片段做简单分组/占位（例如：默认只给一个“要点”积木），确保 UI 不空。
- v1（更像业界）：用 LLM 根据字幕/干货片段生成 Background/Problem/Solution/Case，并把每块关联到若干片段（可点击跳转）。

## 安全与性能
- 自动跳过只在用户本地运行，不新增权限，不上传用户播放行为。
- 定时器频率保持在可接受范围（例如 250ms），并且只在开关开启时运行。

## 测试与部署
- 以“冒烟清单”方式人工验收（更贴近真实使用）：
  1. 自动跳过开/关状态显示正确
  2. 正常播放进入注水段会自动绕开
  3. 手动拖进注水段不会强制绕开
  4. 注水原因显示为中文标签（至少覆盖：重复/广告/无信息增量）
  5. Dashboard 最低可用：点卡片/片段能跳到视频对应时间点（新标签页）
  6. Dashboard 进阶：如果内嵌播放器可行，则能在 Dashboard 内播放并跳转（不可行则确认降级逻辑生效）
  7. 不同视频页切换/刷新后行为仍一致
