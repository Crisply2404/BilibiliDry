# 求职执行清单（Agent 后端方向，7 天可投）

> 目标：让本项目被面试官理解为“Agent 后端核心能力的可落地作品”，即使交付形态是 Chrome 插件（方案 1）。

---

## 1. 你需要在简历里讲清楚的 5 件事

1. **Memory（长期记忆）**：IndexedDB 作为 KV + 向量存储；schema/迁移/清空策略
2. **检索（RAG 的 R）**：跨视频检索（先关键词、后 embedding + cosine）；缓存与延迟指标
3. **调度（Agent Executor）**：chunk 分析调度、并发限制、断点续跑、取消与重试
4. **工具调用/权限**：content script 与 service worker 的能力隔离（Key 不进入页面环境）
5. **工程化**：契约（message schema）、测试、可观测性（最少也要有 latency/token 统计）

---

## 2. 简历可直接用的项目要点（草案）

- 设计并实现 Chrome MV3 “视频脱水 Agent”，基于字幕增量分块分析，30 秒内产出可交互的“干货热力图”与一键跳过策略，显著降低长视频无效观看时间。
- 实现本地 Long-term Memory：基于 IndexedDB 持久化视频片段索引与（可选）embedding，支持跨视频语义检索与一键跳转时间戳。
- 构建 Agent 调度与成本控制：chunk 并发限制、结果缓存、断点续跑与可取消任务，降低重复推理与等待。
- 采用能力隔离的插件架构：API Key 仅在扩展后台持有，通过类型化消息接口提供最小权限调用，避免密钥泄露到页面环境。

---

## 3. 1 周投递节奏（建议）

- Day 1-3：把“可演示闭环”做出来（热力图+跳过+字幕获取）
- Day 4-6：补齐“后端视角的亮点”（Memory/检索/调度/安全/测试）
- Day 7：统一打磨材料（README 架构图、性能指标、录屏、简历 bullets、面试讲解稿）

---

## 4. 面试讲解提纲（5 分钟）

1. 问题与目标（长视频注水、定位干货）
2. 架构图（content script / service worker / Gemini / IndexedDB）
3. 关键链路（增量分块 → segments → 跳过策略 → memory/检索）
4. 成本与性能（并发/缓存/首屏 SLA）
5. 安全与隐私（BYOK、最小权限、不落日志）
6. 复盘与下一步（OCR、ANN、可选后端增强版）
