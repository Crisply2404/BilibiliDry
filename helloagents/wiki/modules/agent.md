# agent

## 目的
把字幕转成“可执行的观看策略”：分段、注水识别、摘要与增量更新，保证“边看边出”体验。

## 模块概述
- **职责:**
  - 字幕分块（按时间窗口）
  - 注水识别输出：`segments[]`（WATER/DRY + confidence）
  - 低延迟：先出热力图与跳过列表，再补全摘要/检索向量
- **状态:** 📝规划中
- **最后更新:** 2026-01-27

## 规范

### 需求: 增量分析（边看边出）
**模块:** agent
从 0 秒开始按 chunk 分块分析，优先产出“可跳过信息”（WATER/DRY + 时间段），随后补齐摘要与 embedding。

#### 场景: 首屏 30 秒内可用
前置条件：字幕可拉取
- 预期结果：在用户打开视频后 30 秒内，热力图出现第一批结果（至少覆盖前 3-5 分钟或前 N 个 chunk）

## 依赖
- extension（字幕输入、播放状态）
- memory（持久化结果、断点续跑）
