# memory

## 目的
实现跨视频语义检索与“记住我看过什么”：本地存储 segments 与 embedding，并提供查询 API。

## 模块概述
- **职责:**
  - IndexedDB schema + 迁移
  - embedding 生成与缓存（只对干货片段）
  - 检索：cosine 相似度 Top-K（MVP 线性扫描）
- **状态:** 📝规划中
- **最后更新:** 2026-01-27

## 规范

### 需求: 跨视频搜索
**模块:** memory
用户输入自然语言 query，返回最相关的片段（含视频标题+时间戳+摘要）。

#### 场景: 小规模数据可用
前置条件：本地至少分析过 3 个视频
- 预期结果：查询延迟 < 300ms（不含 embedding API 调用）；结果可跳转到对应视频时间戳
