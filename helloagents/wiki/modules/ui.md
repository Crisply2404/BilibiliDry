# ui

## 目的
用最少交互把“干货路径”呈现出来：热力图、跳过、搜索、导出与设置。

## 模块概述
- **职责:**
  - 热力图进度条（注入到 B站播放器）
  - 控制按钮（跳过、自动跳过开关；按注水原因类型过滤）
  - 搜索面板（跨视频检索结果列表）
  - 导出面板（Markdown 预览/复制/下载）
- **状态:** 🚧开发中
- **最后更新:** 2026-02-02

## 规范

### 需求: 低打扰但可发现
**模块:** ui
默认仅展示一个小浮层入口；需要时展开侧边栏/弹窗，不遮挡播放器核心区域。

### 需求: 可解释注水 + 可控跳过
- Heatmap hover 提示注水原因（例如 REPEAT/AD/NO_NEW_INFO）。
- 自动跳过遵循 `waterFilter.enabledTypes`（默认只跳过：重复/无信息增量/广告；不默认跳过寒暄/跑题）。
